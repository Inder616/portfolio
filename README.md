## Featured Projects

### 📊 HR Recruitment Analytics Dashboard

**Power BI · SQL · DAX · Power Query**

<a href="https://github.com/Inder616/Recruitment-Funnel-Hiring-Analytics-Dashboard">
View Project →
</a>

A recruitment funnel dashboard analysing **408 requisitions** from manpower requirement through offer, acceptance and joining.

**What I analysed**
- Recruitment funnel conversion
- Open vs closed positions
- Offers and acceptances
- Stage-wise turnaround time
- Recruitment KPIs
- Position-level performance

**Key finding:**  
The largest delay occurred between **requisition and offer**, averaging approximately **21 days**.
